# Thrombocytopenia Risk Calculator for Colorectal Cancer Chemotherapy

Browser-based research-use calculator implementing Model A, a longitudinal
prediction model for the per-cycle probability of any chemotherapy-induced
thrombocytopenia (CTCAE grade 1-4 versus grade 0) in patients treated for
colorectal cancer.

## Publication status

Source candidate v1.4 was generated by Script 25C and passed the complete
cross-tool, confidentiality and local-browser certification performed by Script
26C. Release v1.1 is certified for GitHub Pages deployment. Verification of the
live URL remains pending until the deployment commit is recorded by Script 26D.
The model has been internally validated; external and prospective validation
remain pending.

## Hosting architecture

The GitHub Pages edition uses Shinylive/webR. R, Shiny and the prediction
engine execute locally in the visitor's browser; no remote R server receives
the values entered into the calculator. GitHub Pages serves only static files.

The public application is hosted as a static GitHub Pages site. No shinyapps.io
account or continuously running R server is required.

## Inputs and output

Inputs are regimen, treatment cycle, age at the start of the current treatment
line, baseline platelet count and baseline haemoglobin. Treatment-line number
is not requested and is not a fixed-effect predictor.

The application returns a continuous predicted probability and a 95% parametric
interval based on fixed-effect covariance. It also displays the risk trajectory
over the regimen-specific supported horizon and issues explicit warnings for
limited support or extrapolation.

The interval does not incorporate uncertainty from random-effect variances, the
recalibration intercept, model selection, internal validation or external
transportability.

## Confidentiality architecture

The repository contains only source code, static styles, a parameter-level
public artefact and synthetic self-test cases. It contains no individual
observations, patient identifiers, observed clinical cases or fitted glmmTMB
object. See PRIVACY.md and SECURITY.md.

## Run as a conventional local Shiny app

```r
install.packages(c("shiny", "bslib", "ggplot2", "digest"))
shiny::runApp(".", host = "127.0.0.1", port = 8787)
```

## Export and preview the browser-only edition

```r
install.packages(c("shinylive", "httpuv"))
shinylive::export(".", "_site", wasm_packages = TRUE)
httpuv::runStaticServer("_site", port = 8787)
```

Do not open `_site/index.html` directly from the filesystem; serve the directory
over HTTP as shown above.

## GitHub Pages

The included workflow constructs a temporary runtime directory containing only
the four certified application files, verifies their SHA-256 signatures, builds
the browser edition and deploys it to GitHub Pages after pushes to `main`.

## Clinical-use statement

This application provides informational predictive support. It does not
prescribe treatment, replace laboratory monitoring or professional judgement,
or establish causal differences between regimens. Predicted probabilities must
not be interpreted as externally validated estimates.
